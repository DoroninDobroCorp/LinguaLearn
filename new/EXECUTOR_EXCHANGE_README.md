# Обмен заданиями с внешним исполнителем

Эта папка используется только для передачи ТЗ, отчётов, diff и результатов проверок между владельцем, внешним исполнителем и ревьюером.

## Структура

- `outgoing/` — утверждённые ТЗ для исполнителя.
- `incoming/` — handoff-отчёты, patch/diff и результаты тестов от исполнителя.

## Правила

1. Исполнитель читает актуальное ТЗ из `outgoing/` целиком.
2. Результат кладёт в `incoming/` под именем, указанным в ТЗ.
3. Секреты, cookies, tokens, passwords, proxy credentials и полные environment-файлы сюда не помещать.
4. Не заменять исходное ТЗ: для уточнений создавать отдельный файл с UTC timestamp.
5. Файлы из `incoming/` не считаются проверенными или разрешёнными к deployment, пока владелец явно не передал их ревьюеру и не получил подтверждение.
6. Эта папка не является местом для runtime-кода и не должна добавляться в deployment/build context.
