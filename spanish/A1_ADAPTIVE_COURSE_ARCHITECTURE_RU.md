# Архитектура полноценного курса испанского A1

Этот документ описывает действующие продуктовые инварианты A1. Раздел A2 этой системой не изменяется.

## Свободный темп без фиктивного ускорения

Пользователь может заниматься 15 минут, один раз в неделю или несколько часов подряд. Главная страница хранит выбранный ориентир 15/30/60 минут, всегда показывает один лучший следующий шаг и после основного маршрута предлагает продолжение без дневного лимита.

Практика и подтверждение удержания разделены:

- любая попытка сохраняется и влияет на знакомство/точность;
- правильная попытка раньше окна планового повторения считается дополнительной практикой (`retentionCredit=false`);
- ранняя практика не переносит обязательную дату и не увеличивает стабильность памяти;
- ошибка учитывается сразу, переводит тему в relearning и назначает короткое повторение;
- окно до 24 часов позволяет заниматься примерно в одно и то же время суток без наказания за часы.

## Когда тема действительно освоена

Статус `mastered` выдаётся только при одновременном выполнении всех условий:

- не менее 6 попыток;
- не менее 4 зачётных интервальных повторений;
- успешные повторения минимум в 4 разные календарные даты;
- прошло не менее 14 суток с первого знакомства;
- прогнозируемая стабильность не менее 14 дней;
- итоговый score не ниже 85.

Высокий тренировочный score сам по себе никогда не рисуется как «освоено». Общий процент курса показывает готовность к завершению, а отдельный `familiarityPercent` — текущую знакомость с материалом.

## Логика следующего шага

`getA1TodayPlan` строит план под желаемое время, но не блокирует продолжение:

1. просроченные грамматические повторения;
2. просроченные карточки слов;
3. следующая открытая тема;
4. самый слабый из listening/speaking/reading/writing;
5. сюжетная практика.

При большом долге повторения остаются первым советом, но новая тема остаётся доступна как осознанный дополнительный выбор. Это сохраняет мотивацию интенсивного ученика и не ломает расписание редкого ученика.

## Честные навыковые зачёты

- Listening/reading: клиент не получает ключи ответов; сервер сравнивает ответы с каноническим заданием.
- Writing: текст оценивается Gemini по опубликованной рубрике; при недоступности модели попытка не засчитывается.
- Speaking: браузер делает настоящую запись MediaRecorder; сервер принимает аудио не короче 3 секунд и оценивает выполнение задачи, грамматику, лексику и произношение.
- Прямой API для произвольного выставления балла отключён.
- Для завершения каждого навыка нужны минимум 3 зачёта, минимум в 2 разные даты и лучший балл не ниже 70.

Модульные checkpoint-задачи проверяются сервером по каноническим ответам. Клиентские поля `correct`, `score` и `passed` не являются доверенными. Продуктивное письмо внутри checkpoint пока является тренировкой; официальный зачёт письма находится в разделе «4 навыка».

## Завершение A1

Курс завершён только когда одновременно:

- все 30 тем имеют фазу `mastered`;
- все 650 основных лемм созрели в обеих направлениях карточек (не менее 4 повторений и интервал 14+ дней);
- сданы все 4 навыка;
- прошло минимум 14 дней с начала курса.

API exact-once использует `eventId`; повторная доставка не создаёт второй прогресс. Перед миграцией production создана проверенная SQLite online-backup копия вне worktree.
